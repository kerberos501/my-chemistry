# My Chemistry

A chemistry book in four parts: 51 short lessons, each one spread. Published at https://kerberos501.github.io/my-chemistry/

- Every lesson in Part 1 has a working model on its right-hand page. `docs/visuals.md` lists the model for each lesson and what is still planned for Parts 2 to 4.
- Part 1 ends with a review page of 24 practice questions (`src/data/review.js`).
- The models live in `src/model-*.js` and are listed by lesson in `src/models.js`.
